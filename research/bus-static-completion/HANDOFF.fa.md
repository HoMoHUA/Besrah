# بسته داده راهنمای خطوط بِسراه

این بسته برای بررسی و مصرف داده ثابت خطوط است؛ برنامه، رابط کاربری یا سرویس زمان رسیدن نیست.

## محتوا

- `data/bus/guide/lines.json`: فهرست شناسه های خام خطوط و گونه های مسیر.
- `data/bus/guide/routes.json`: پرونده هر مسیر، ایستگاه ها، سکوها، اعضای خام و هندسه قطعه ای.
- `data/bus/guide/stops.json`: موجودی عناصر ایستگاهی و عضویت آن ها در مسیرها.
- `data/bus/guide/facilities.json`: نامزدهای پایانه و تاسیسات ثبت شده، نه فهرست رسمی پایانه های شهری.
- `data/bus/guide/endpoint-derivations.json`: شاهد دو برچسب نمایشی مشتق شده برای خط ۴۲.
- `data/bus/guide/manifest.json`: منبع، کیفیت، شمارش ها و هش فایل های داده.
- `data/bus/mashhad-bus.sqlite`: بانک اصلی، بدون تغییر بایت های منبع.
- `research/bus-static-completion/`: گزارش فارسی، ممیزی، موارد نیازمند تطبیق، بازبینی و نتیجه رفع ایرادها.

## اعتبارسنجی پس از استخراج

برای خواندن JSON وابستگی خاصی لازم نیست. برای اجرای آزمون، Node.js و Python 3 موجود در مسیر اجرا لازم اند. از ریشه پوشه استخراج شده اجرا کنید:

```bash
node --test tests/data/bus-guide-integrity.test.mjs
```

این آزمون بانک را فقط خواندنی باز می کند، همه رکوردهای راهنما را با آن مقایسه می کند و شش تغییر نامعتبر آزمایشی را فقط در حافظه رد می کند؛ داده روی دیسک تغییر نمی کند.

## محدودیت مهم

این بسته، مجموعه بررسی شده داده موجود است؛ **کامل بودن تمام خطوط فعال مشهد تایید نشده است**. داده جاری قابل تایید برای مسیر و ایستگاه های خطوط گزارش شده ۸۳۲ و ۸۳۳ همچنان لازم است. پرونده های تاریخی، سرنخ های شماره خط و متن خبرها به خطوط فعال یا مسیرهای ساختگی تبدیل نشده اند.

نام، کد و مقدار خام حفظ شده اند. برچسب نمایشی دارای شاهد را با مقدار خام یکسان فرض نکنید. جهت، فعال بودن سرویس، پیوستگی مسیر برای ناوبری و زمان رسیدن، تایید مستقل ندارند.

این یک نمای داده ذخیره شده و بررسی شده است؛ بازسازی بانک خام، فایل های راهنما را خودکار بازتولید نمی کند. تا زمانی که نمای تازه با منبع و هش جدید بررسی نشده، از ترکیب بانک جدید و راهنمای قدیمی استفاده نکنید. بازسازی کامل بانک خام و ابزارهای اپ در مخزن کامل پروژه قرار دارند.

داده مشتق شده OSM با انتساب **© OpenStreetMap contributors** و مجوز **ODbL-1.0** نگهداری می شود. PDF و متن کامل مقاله های منابع ثالث در این بسته بازنشر نشده اند.

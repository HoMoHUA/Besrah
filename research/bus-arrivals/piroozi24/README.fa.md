# نتیجه بررسی ایستگاه پیروزی ۲۴

تاریخ بررسی: ۳۰ اکتبر ۲۰۲۶. رابط و سرویس های آنلاین بِسراه تغییر نکردند.

## نتیجه کوتاه

**صفحه واقعی ایستگاه و مسیر درخواست اطلاعات خطوط عبوری پیدا شد؛ اما پیش بینی عددی تازه و اتصال قابل استفاده در محصول هنوز تایید نشده است.**

لینک ارسالی بدون تغییر نگهداری شد و در مرورگر عادی به صفحه ایستگاه در نشان رسید.[1][2]

- شناسه مکان در نسخه وب نشان: `9692be87527100142598f9a6c7d1e140`.
- رکورد متناظر نام و مختصات در بانک OSM: `osm:node:264158011`، با کد ثبت شده `1091`.
- فاصله دو مختصات، با محاسبه کروی، حدود ۱٫۷۴۹ متر است. این تطبیق مکانی، تایید رسمی شناسه API شهرداری یا برابری با `poiHash` در API تجاری نشان نیست.
- چهار خط نمایش داده شده در برگه حمل و نقل عمومی: **۹۱، ۹۸، ۴ و ۱۰۹۳**.[2]

## آزمون بازخوانی

در یک نشست پیوسته و قابل مشاهده مرورگر، برگه اصلی «حمل و نقل عمومی» باز شد. کد درخواست یا پاسخ دستکاری نشد و رمزگشای اختصاصی ساخته نشد.

- مشاهده اول: **۱۰:۱۱:۲۷ به وقت تهران**.
- مشاهده دوم: **۱۰:۱۲:۳۷ به وقت تهران**، با فاصله ۷۰٫۰۰۸ ثانیه.
- در فاصله دو مشاهده، درخواست تازه ای از خود صفحه ثبت شد.
- پس از بارگذاری کامل و در هر دو مشاهده، زمان هر چهار خط **«نامشخص»** بود.

«نامشخص» را نه صفر دقیقه، نه نبودن اتوبوس و نه غیرفعال بودن خط حساب نکردیم. برچسب های عددی گذرای زمان بارگذاری اولیه نیز بدون زمان اندازه گیری ارائه دهنده، پیش بینی تازه و تایید شده حساب نشدند. این آزمون، دقت واقعی رسیدن اتوبوس در محل را تایید نمی کند.

## مسیر فنی مشاهده شده

این نشانی از درخواست های واقعی صفحه به دست آمد، نه از حدس زدن مسیر API:[3]

```text
https://neshan.org/maps/pwa-api/transportation/passing-lines/mashhad/9692be87527100142598f9a6c7d1e140
```

درخواست های محدود مستقیم و با پروکسی موجود، بدون ارسال کلید API، توکن یا کوکی، HTTP 200 گرفتند. با این حال، بدنه با وجود سرآیند `application/json`، با تجزیه معمول JSON خوانده نشد. بنابراین HTTP 200 را به معنی داشتن یک API عمومی مستند و آماده استفاده در بِسراه حساب نکردیم. قرارداد رسمی، قالب پایدار و زمان تولید پیش بینی هنوز تایید نشده اند.[3]

## محدودیت استفاده محصولی

بخش محدودیت های شرایط استفاده منتشر شده نشان، برداشت خودکار، استخراج و استفاده مجدد از داده و مهندسی معکوس را محدود می کند. دسترسی فنی یک صفحه، اثبات مجوز استفاده در محصول دیگر نیست. به همین دلیل جمع آوری انبوه، بازنشر داده یا اتصال API داخلی به سرویس آنلاین انجام نشد؛ مسیر پایدار نیازمند دسترسی یا توافق تایید شده با ارائه دهنده است.[4]

## موارد باز

- دریافت پیش بینی عددی تازه همراه با زمان تولید یا اندازه گیری ارائه دهنده.
- روشن شدن مجوز، قالب، محدودیت درخواست و شرایط استفاده از خوراک زمان رسیدن.
- تطبیق شناسه رسمی ایستگاه و خطوط. عنوان مبدا بعضی خطوط در OSM با نمایش نشان متفاوت است و خط ۴ در عضویت مستقیم همین رکورد OSM وجود ندارد؛ این تفاوت ها بدون منبع تایید کننده اصلاح نشدند.
- اگر روی نسخه موبایل نشان در همان زمان، عدد معتبر نمایش داده شود، تفاوت نسخه وب و موبایل باید جدا بررسی شود.

## شواهد

- `link-probes.json`: تغییر مسیر لینک کوتاه و نتیجه درخواست مستقیم و پروکسی.
- `api-probes-sample1.json`: وضعیت HTTP، زمان دریافت و هش بدنه درخواست های محدود.
- `browser-sample1.json` و `browser-sample2.json`: دو مشاهده پذیرفته شده و درخواست بازخوانی خود صفحه.
- `identity-corroboration.json`: تطبیق نام و مختصات و عضویت مسیر در بانک فعلی.
- `findings.json`: نتیجه ساخت یافته و محدودیت ها.
- یک برداشت `about:blank` رد شد و هیچ داده ای از آن به عنوان مشاهده ایستگاه پذیرفته نشد.

# تعامل

## بازخورد برای هر کار

| کار | بازخورد فوری | بعد از پاسخ سرور |
| --- | --- | --- |
| افزودن به سبد | فشار، تیک، پرواز | شمارنده و toast؛ خطا ← برگشت دکمه و پیام زیر آن |
| تغییر تعداد | رقم می‌غلتد | جمع‌ها می‌غلتند؛ خطای موجودی ← برگشت عدد و `warning` |
| حذف ردیف | شن | — (امکان «برگرداندن» در toast تا ۵ ثانیه) |
| علاقه‌مندی | قلب پر، حلقه و جرقه | خطا ← قلب خالی و toast |
| کد تخفیف | چرخنده روی «اعمال» | سبز یا لرزش قرمز با پیام |
| پرداخت | چرخنده با عرض ثابت | انتقال به درگاه |

قاعده: نتیجهٔ خوش‌بینانه را نشان دهید و اگر سرور رد کرد، با توضیح برگردانید.

## لمس، نشانگر، کیبورد

- **فشار**: `.el` از نقطهٔ لمس؛ در دسکتاپ هم با کلیک. hover فقط روی دستگاه‌های دارای نشانگر (`@media (hover: hover)`).
- **کشیدن**: ردیف سبد و toast به چپ؛ ویجت توپی هر جهت؛ محصول به کیف. هر کشیدن یک جایگزین بدون کشیدن دارد (دکمه).
- **کنترل‌های داخل کارت کشیدنی** (`button`، `a`، `input`، `label`، `[data-hm7-nodrag]`) کلیک خودشان را دارند.
- **فوکوس**: حلقهٔ ۲px `accent` با فاصلهٔ ۲ تا ۳px، فقط با `:focus-visible`.
- **کیبورد**: تب‌ها و رادیو با جهت‌ها (برعکس برای RTL)، اسلایدر با جهت‌ها/Home/End، تعداد با بالا/پایین، ردیف سبد با Delete، منو با Escape.

## وضعیت‌های هر کنترل

| وضعیت | ظاهر |
| --- | --- |
| عادی | — |
| hover | روشن‌تر شدن ۶٪ یا لبهٔ `accent` ۲۲٪ |
| فشار | کشسان از نقطهٔ لمس |
| فوکوس | حلقهٔ ۲px `accent` |
| انتخاب‌شده | پر با `accent` یا `accent-soft`، تیک |
| غیرفعال | شفافیت ۰٫۴۵، بدون سایه، `cursor: not-allowed` |
| بارگذاری | `aria-busy="true"`، چرخنده، عرض ثابت |
| خطا | لبهٔ `sale` و یک لرزش |

## فرم‌ها

- برچسب همیشه بالای فیلد، هرگز فقط placeholder.
- خطا بعد از ترک فیلد یا ارسال؛ اولین فیلد خطادار فوکوس می‌گیرد.
- `inputmode` و `autocomplete` درست: موبایل `tel`، کد پستی `numeric`، نشانی `street-address`.
- ارقام فارسی و عربی ورودی را قبل از ارسال لاتین کنید (`HM7.shop.latin`).

از HoMoGram v1.6: جابه‌جایی دو آیکون با چرخش، کوچک‌شدن و محوشدن.

- `.im` با دو فرزند `.on` و `.off` (آیکون `.hms` یا متن). `HM7.ui.morph(im, state?)` یا `[data-morph]` روی دکمه.
- `.off`: `scale(.32) rotate(-24deg)`، شفافیت ۰، `blur(3px)`. transform ۴۸۰ms `--sk`، شفافیت ۳۶۰ms.
- کاربردها: علاقه‌مندی، افزودن ← افزوده شد، نمایش رمز، روز/شب. اگر دکمه `aria-pressed` دارد، morph آن را هم عوض می‌کند.

- `.cm-list` > `.hm7-notif-row` > `.hm7-notif.cm-line` + دو `.hm7-notif__act` («بعداً می‌خرم» و حذف). `HM7.swipeDismiss(card, { stage: list, onDismiss, onAction })`.

- در تم روشن ذرات «جوهری»اند (رنگ متن و برند روی سطح سفید)؛ در تم تیره نوری.

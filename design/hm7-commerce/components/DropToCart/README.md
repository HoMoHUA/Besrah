کشیدن محصول به سبد: کیف خرید شیشه‌ای مثل ورق کشسان روی محصول نزدیک‌شده کشیده می‌شود و با رها کردن، موج می‌زند.

- افزوده از کیت نور غوطه‌ور (پوشهٔ کشسان هارمونی ۷)، اینجا برای «مقایسه» یا «سبد سریع» در صفحه‌های دسته و جشنواره.
- `.hm7-stage` با `.hm7-folder` (کیف، شش خانه) و محصولات `.hm7-icon[data-drag]` با `--glow`. `HM7.iconDrag(stage, { onDrop })`.
- قبل از تماس حداکثر ۶px برآمدگی؛ محصول جذب نمی‌شود و زیر انگشت می‌ماند. رها کردن: موج سه‌حلقه‌ای، نشستن در خانه، درخشش لبه.
- همیشه راه بدون کشیدن هم بدهید (دکمهٔ افزودن روی کارت)؛ کشیدن میان‌بُر است، نه تنها راه.

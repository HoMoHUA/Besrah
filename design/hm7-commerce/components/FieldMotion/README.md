حرکت فیلد متن: هر فوکوس، تایپ، لمس و اشاره یک تغییر اندازهٔ فنری کوچک می‌دهد، و با هر کلید حاشیهٔ فیلد درست در محل caret می‌درخشد («درخشش تایپ» از HoMoGram V5).

- یک بار `HM7.fieldMotion(root)` (پیش‌فرض `document`): همهٔ `input`های متنی و `textarea`های زیر آن، حتی آن‌هایی که بعداً رندر می‌شوند (رویدادها واگذارشده‌اند). چک‌باکس، رادیو، فایل و اسلایدر حرکت نمی‌کنند؛ فیلد غیرفعال و فقط‌خواندنی هم نه.
- **فنر:** یک فنر کم‌میرا برای هر فیلد (`k=420 c=17`، یکی دو نوسان).

| رویداد | حرکت |
| --- | --- |
| فوکوس | ضربهٔ بزرگ‌شدن، عبور تا ~۱٫۹٪، ماندن روی ۱٫۰۱۲ تا وقتی فوکوس دارد |
| هر کلید | کش‌آمدن پهنا و فشرده‌شدن ارتفاع (~۲٫۷٪)؛ حذف برعکس |
| لمس پیش از فوکوس | فرورفتن |
| اشارهٔ ماوس | بالاآمدن ملایم |
| ترک فیلد | کوچک‌شدن کوتاه و برگشت به ۱ |

- **درخشش تایپ:** لایهٔ ثابت `.hm7-field-slime` روی قاب فیلد؛ مرکز نور در محل caret (با یک div آینه اندازه‌گیری می‌شود؛ در فیلد رمز با تعداد نقطه‌ها)، ۸۵٪ برای ۱۴۰ms و بعد ۵۰۰ms محو. رنگ همان توکن‌های `reveal-*`. با اسکرول پنهان می‌شود.
- **دسترس‌پذیری:** با `prefers-reduced-motion` نه فنر هست نه درخشش؛ در رنگ‌های اجباری درخشش پنهان است. حرکت هرگز جای فیلد را در چیدمان عوض نمی‌کند (فقط `transform`).
- `HM7.fieldMotion(root).destroy()` همه را جدا می‌کند.

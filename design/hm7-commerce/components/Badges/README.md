نشان‌ها وضعیت را کوتاه می‌گویند؛ همیشه متن دارند و فقط رنگ نیستند.

- `.cm-badge--sale` تخفیف («۱۷٪ تخفیف»)، `--new` «جدید»، `--ok` «موجود» / «ارسال رایگان»، `--warn` «فقط ۲ عدد»، `--solid` «حراج» روی تصویر.
- ارتفاع ۲۲px، متن ۱۱px وزن ۷۰۰، کپسولی. حداکثر دو نشان روی هر کارت؛ تخفیف همیشه اول.
- شمارندهٔ سبد `.cm-count` روی `.cm-cartbtn`: با `data-n="0"` پنهان، با تغییر عدد رقم‌ها می‌غلتند و دکمه می‌پرد (`HM7.shop.roll` و `bump`).

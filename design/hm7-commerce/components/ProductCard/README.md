کارت محصول: تصویر روی زمینهٔ رنگی خود محصول، نشان تخفیف، قلب علاقه‌مندی و دکمهٔ افزودن که محصول را به سبد پرواز می‌دهد.

- `article.cm-product[data-cm-product]` با `.cm-product__media` (`--tint` = رنگ غالب محصول به‌صورت RGB)، `.cm-product__meta` (عنوان دوخطی، امتیاز)، `.cm-product__foot` (قیمت + دکمه).
- hover: ۴px بالا آمدن با فنر و `shadow-raised`؛ تصویر ۱٫۰۷ و −۳°. نور لبهٔ v1.6 با `.rv`.
- `.cm-fav[data-cm="fav"]`: قلب توخالی ← پر با Icon Morph، حلقهٔ `sale` و شش جرقه.
- `.cm-add[data-cm="add"]`: آیکون کیف ← تیک، کپی تصویر روی کمان به `[data-cm-cart]` می‌پرد (۷۶۰ms)، سبد می‌پرد و شمارنده می‌غلتد.
- ناموجود: `.is-out` تصویر خاکستری، نشان «ناموجود» به جای قیمت و دکمهٔ «خبرم کن».
- گرید: ۲ ستون زیر `bp-md`، ۳ تا `bp-lg`، ۴ بالاتر؛ فاصله `space-12` / `space-20`.

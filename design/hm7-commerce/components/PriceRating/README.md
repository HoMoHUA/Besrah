قیمت و امتیاز: عدد فارسی با جداکنندهٔ هزارگان، تومان کوچک کنارش؛ قیمت قبلی بالای قیمت فعلی با نشان درصد.

- `.cm-price` > `.cm-price__was` (`s` + نشان درصد) + `.cm-price__now` (`b` + `small`). `--sale` قیمت فعلی را `sale` می‌کند؛ `--lg` برای صفحهٔ محصول (۲۶px، ۹۰۰).
- `HM7.shop.money(1250000)` → «۱٬۲۵۰٬۰۰۰ تومان»؛ `{ unit: false }` بدون واحد. درصد با `HM7.shop.pct(was, now)`، گرد به پایین نه بالا.
- ارقام هم‌عرض (`tabular-nums`) تا با تغییر عدد، چیدمان نلرزد؛ تغییر با `HM7.shop.roll`.
- امتیاز: `.cm-rating` > `.cm-stars` با `--r` (۰ تا ۵) — پر شدن جزئی ستاره‌ها از راست — و عدد امتیاز و تعداد نظر کنارش. ستاره بدون عدد نیاید.

صحنهٔ غوطه‌ور: زمینهٔ کبالتی با روبان نور «۷» که آرام می‌لغزد؛ هر شیشه‌ای رویش نور انگشت را می‌گیرد.

- `.hm7-stage` روی یک ظرف (هیرو، بنر حراج، برگهٔ فیلتر، ویجت). `position: relative` و `overflow: hidden` خودش دارد.
- روی صحنه فقط `.hm7-glass` بگذارید (دکمه `.hm7-btn`، چیپ `.hm7-chip`، جستجو `.hm7-search`، منو `.hm7-menu`، پنل `.hm7-panel`)؛ متن سفید.
- `HM7.light(stage, { radius: 220 })` نور نقطهٔ لمس را روشن می‌کند: شیشه‌ها لبهٔ رو به نور را روشن‌تر نشان می‌دهند.
- در هر صفحه حداکثر یک یا دو صحنه؛ بقیهٔ صفحه سطح `surface` روی `bg` است. صحنه در تم تیره هم کبالتی می‌ماند.
- نکنید: متن بلند یا فرم چندخطی روی صحنه؛ کارت محصول کامل روی صحنه (برای آن `FlashDeal` هست).

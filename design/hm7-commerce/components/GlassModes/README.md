شیشه در حالت‌های دسترس‌پذیری: «شفافیت کمتر» شیشهٔ مات را سطح سفید با لبه می‌کند، «کنتراست بیشتر» لبهٔ ۱٫۵px به رنگ `ink` و متن دوم پررنگ‌تر می‌دهد، «رنگ‌های اجباری» به رنگ‌های سیستم برمی‌گردد.

- خودکار با `prefers-reduced-transparency`، `prefers-contrast: more` و `forced-colors: active`؛ برای تنظیم درون سایت `data-hm7-transparency="reduce"` و `data-hm7-contrast="more"` روی `<html>`.
- کنتراست بیشتر توکن‌ها را جابه‌جا می‌کند: `muted` ← `#3a3e6b` (روشن) / `#c9ccf3` (تیره)، `line` پررنگ‌تر. شیشهٔ صحنه بدون blur با کبالت تخت.
- هر دو حالت را همیشه با بیشترین محتوای زیر شیشه (تصویر، فهرست اسکرول‌شونده) آزمایش کنید.

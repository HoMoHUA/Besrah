اسکلت بارگذاری هم‌شکل محتوای واقعی؛ برق آن از راست به چپ می‌رود و محتوا با ۸px بالا آمدن جایش را می‌گیرد.

- `.cm-skel` با `--media` (مربع تصویر) و `--line` (۱۲px). شکل و اندازه دقیقاً مثل کارت نهایی تا جابه‌جایی چیدمان صفر باشد.
- برق ۱٫۴ ثانیه `--cm-std`؛ در `prefers-reduced-motion` ثابت.
- محتوای رسیده `.is-loaded` (۵۰۰ms). برای اسکرول بی‌پایان، ۴ کارت اسکلت پیش از رسیدن به ته فهرست (IntersectionObserver).

حراج لحظه‌ای: قاب نور لبه به رنگ حراج، شمارش معکوس با رقم‌های غلتان و نوار «فروش رفته» که برق می‌زند.

- `.cm-flash.hm7-device` (نور لبهٔ هارمونی ۷ با `--hm7-ember` = `sale`) > `.hm7-stage`. سطح نور با `HM7.edgeGlow(frame, 'strong' | 'medium' | 'soft')`؛ زیر ۱۰ دقیقه `strong`.
- شمارش: `[data-cm="countdown"]` با `data-end` (ثانیه از الان، timestamp یا ISO) و خانه‌های `[data-u="h|m|s"]`؛ دقیقهٔ آخر قرمز می‌درخشد. `HM7.shop.countdown(el, { end, onEnd, urgent })`.
- `.cm-meter` با `--p` (۰ تا ۱) برای درصد فروش؛ متن کنارش همیشه عدد را بگوید.
- رزرو: «رزرو ۱۰ دقیقه‌ای» کالا را برای کاربر نگه می‌دارد؛ بعد از رزرو شمارش رزرو جای دکمه را می‌گیرد و قاب یک موج نور می‌زند. تمام شدن موجودی ← «عضویت در صف انتظار».

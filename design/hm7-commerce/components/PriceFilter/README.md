برگهٔ فیلتر غوطه‌ور: اسلایدر ذره‌ای برای سقف قیمت و چیپ‌های شیشه‌ای؛ تعداد نتیجه با غلتیدن عوض می‌شود.

- افزوده از کیت نور غوطه‌ور: `HM7.particleSlider(el, { value, onInput, label, icon })` فقط روی `.hm7-stage` (ذرات نورند و روی سطح روشن دیده نمی‌شوند).
- عدد سقف قیمت کنار اسلایدر با `money`؛ تعداد نتیجه روی دکمهٔ «نمایش ۱۲۸ کالا». با ۳۰۰ms debounce از سرور بپرسید.
- اسلایدر نقش `slider` دارد؛ جهت‌ها، Home و End. برای بازهٔ دوطرفه دو اسلایدر «از» و «تا» بگذارید.
- برگه در موبایل از پایین با `scrim` می‌آید (`z-sheet`)؛ در دسکتاپ ستون کناری ثابت روی سطح `surface` با فیلترهای ساده.

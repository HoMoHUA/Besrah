اعلان‌های کوتاه فروشگاه: کارت شیشه‌ای مات که از بالا با فنر می‌آید، با کشیدن کنار می‌رود و بعد از زمانش به شن تبدیل می‌شود.

- `HM7.shop.toast(host, { title, text, icon, tint, action, onAction, life })` → همان API کشیدن. `life` پیش‌فرض ۴٫۲ ثانیه؛ hover و فوکوس زمان را نگه می‌دارد؛ `life: 0` ماندگار.
- نوار نازک زمان باقی‌مانده پایین کارت. حداکثر سه toast هم‌زمان؛ تازه‌ترین بالا.
- `role="status"` (خواندن مؤدبانه). خطای مهم را toast نکنید؛ کنار همان فیلد یا دکمه بگویید.
- کاربردها: افزوده شد (با «مشاهدهٔ سبد»)، کد تخفیف اعمال شد، موجود شد (صف انتظار)، سفارش ارسال شد.

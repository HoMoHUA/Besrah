# اندازه‌گیری‌ها از ویدیوهای هارمونی ۷

عددهایی که موتور HM7 از ویدیوهای معرفی (۶۰fps و ۱۰۸۰p) گرفته و این سیستم بر آن‌ها ساخته شده است.

## کشیدن و حذف (ردیف سبد، toast)

| پارامتر | مقدار |
| --- | --- |
| دکمه‌های ظاهرشونده | بیرونی اول، دومی ~۱۰۰ms بعد؛ قطر ۴۴px، فاصله ۱۰px |
| گردن مایع | تا ۱۸px فاصله از لبه |
| باز ماندن | به اندازهٔ عرض دکمه‌ها؛ رهاکردن بعد از ۴۵٪ |
| آستانهٔ حذف | ۱٫۴۵ برابر عرض دکمه‌ها، پرتاب سریع‌تر از ۱۳۰۰px/s، یا ۵۵٪ عرض کارت |
| شروع شن | ۱۰ تا ۲۰٪ بعد از حرکت به چپ، نه در انتها |
| جارو | ۰٫۴۵ ثانیه، جبههٔ دانه‌دانه به پهنای ۲۲٪ عرض |
| جمع شدن | فنر `k=240 c=19`، ۴۵ms فاصله بین ردیف‌ها |
| پاک کردن همه | یک جبهه از پایین به بالا، شیب ۰٫۱۶، ۰٫۶۲ ثانیه |

## کاشی لامپی

| پارامتر | مقدار |
| --- | --- |

| فلش | اوج ~۱۲۰ms |
| تغییر وضعیت | در اوج فلش (~۳۰۰ms) |
| انتشار نور | ۷۶۰px/s تا شعاع ۲۳۰px |
| نور ثابت کاشی روشن | ۳۰٪ |

| --- | --- |

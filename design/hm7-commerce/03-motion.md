# حرکت

## منحنی‌ها

| نام | مقدار | کاربرد |
| --- | --- | --- |
| `--cm-spring` / `--sp` | `cubic-bezier(.34,1.56,.64,1)` | رهاسازی، ورود toast، تیک چیپ، کارت hover |
| `--cm-out` / `--sm` | `cubic-bezier(.16,1,.3,1)` / `(.22,1,.36,1)` | خط پیشرفت، نوار فروش، انتقال صفحه، منو |
| `--cm-std` / `--st` | `cubic-bezier(.4,0,.2,1)` | لحظهٔ فشار، شفافیت، لرزش خطا |
| `--sk` | `cubic-bezier(.68,-0.55,.27,1.55)` | Icon Morph |

این‌ها در `:root` داخل `bundle.css` تعریف شده‌اند. فیزیک افکت‌های غوطه‌ور با فنر واقعی در موتور است (گام ۶ms)، نه منحنی CSS.

## فنرها (اندازه‌گیری از ویدیوهای هارمونی ۷)

| افکت | فنر |
| --- | --- |
| دکمه‌های مایع ردیف | `k=430 c=23` |
| کارت کشیدنی | `k=320 c=30` |
| ویجت توپی | `k=115 c=7` — دوره ~۰٫۶ ثانیه، یک عبور ~۳۵٪ |
| عدسی تب | `k=320 c=24` |
| غشای کیف (پوشه) | رفت `k=640 c=26`، برگشت `k=520 c=15` |
| فیلد متن (`HM7.fieldMotion`) | `k=420 c=17` — فوکوس تا ~۱٫۹٪ و ماندن روی ۱٫۰۱۲، هر کلید ~۲٫۷٪ کش‌وفشار |

## رقص «افزودن به سبد»

1. ۰ms — فشار دکمه (کشسان)، آیکون کیف ← تیک (Icon Morph)، برچسب ← «افزوده شد».
2. ۰ تا ۷۶۰ms — کپی تصویر روی کمانی که تا ۱۷۰px بالا می‌رود، می‌چرخد (±۱۴°) و تا اندازهٔ سبد کوچک می‌شود؛ ۱۴٪ آخر محو.
3. ۷۶۰ms — سبد می‌پرد (۱٫۲۸ ← ۰٫۹ ← ۱)، هالهٔ کبالت، رقم شمارنده می‌غلتد.
4. ۷۶۰ms — toast «به سبد افزوده شد» با «مشاهدهٔ سبد».
5. ۲٫۶ ثانیه — دکمه به حالت عادی برمی‌گردد.

## رقص «حذف از سبد»

1. کشیدن به چپ: دکمه‌ها از لبهٔ ردیف با گردن مایع جدا می‌شوند (بیرونی اول، دومی ~۱۰۰ms بعد).
2. سطل یا کشیدن بیش از ۱٫۴۵ برابر عرض دکمه‌ها: دکمه‌ها محو، ردیف از راست به چپ با جبههٔ دانه‌دانه شن می‌شود.
3. ردیف‌های پایینی با فنر بالا می‌آیند؛ جمع‌ها می‌غلتند.

## لایهٔ Liquid Glass

| رفتار | مقدار |
| --- | --- |
| گروه شیشه (`HM7.cluster`) | فنر `k=250 c=18`، ۴۵ms فاصله از نزدیک‌ترین به دکمه؛ بستن ۳۰ms فاصله، برعکس |
| پنل از دکمه (`HM7.morph`) | فنر `k=270 c=23`؛ محتوا از ۲۸٪ تا ۶۸٪ مسیر؛ گوشه از کپسول تا شعاع پنل |
| نوار کوچک‌شونده (`HM7.dock`) | آستانهٔ ۲۸px رو به پایین و ۲۰px رو به بالا؛ انتقال‌ها ۵۵۰ms فنری |
| ظاهر شدن با نور | ۵۶۰ms؛ محتوا با ۱۲۰ms تأخیر |
| لبهٔ اسکرول | بالا بعد از ۴۸px اسکرول به ۲۸px می‌رسد (scroll-driven)، پایین ثابت ۲۸px |

`HM7.springEasing(k, c)` هر فنر را به یک `linear()` برای CSS و WAAPI تبدیل می‌کند: `el.animate(frames, { duration: e.duration, easing: e.easing })`.

## صدا با حرکت

صداها از همان رویدادی پخش می‌شوند که حرکت را می‌سازد (اصل یک پارتیتور): `add` در فریم رسیدن به سبد، `tileOn` در اوج فلش، `dissolve` با شروع جارو، `snap` در فریم پاره شدن پل. جدول کامل در «صدا و لرزش».

## قواعد

- در هر صفحه حداکثر یک حرکت پرانرژی هم‌زمان (پرواز، حذف، موج). بقیه آرام.
- حرکت از جای لمس شروع می‌شود و به همان‌جا جواب می‌دهد.
- هیچ انیمیشنی جلوی کار را نمی‌گیرد: دکمه بلافاصله کار می‌کند، انیمیشن فقط بازخورد است.
- `prefers-reduced-motion`: فنرها مستقیم به مقصد، بدون پرواز (فقط شمارنده عوض می‌شود)، بدون برق و چرخش، ذرات ۰٫۱۵ ثانیه.

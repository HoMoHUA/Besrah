# USER-FLOWS-AND-OWNER-QA

آدرس: `https://besrah.arklyn.ir/` (بدون ورود؛ آدرس مخفی است ولی خصوصی نیست). **تا مالک خودش آزمون نکند، وضعیت تلگرام `AWAITING_HUMAN` است.**

## چک لیست ۱۰ دقیقه ای (Telegram رسمی، Huawei Android 10)

| # | گام | انتظار |
|---|---|---|
| 1 | باز کردن Mini App ← خانه | کاشی ها: بسراه، بسفود، رهیاب، بسخرید، بسپی (به زودی). فونت AzarMehr، بدون سرریز افقی |
| 2 | بسفود ← نوشتن «چلو کباب» | فهرست با برچسب «قدیمی» و «لحظه ای نیستند»؛ قیمت نامشخص صفر نیست |
| 3 | «منو و جزئیات» روی یک فروشگاه | منو با دسته ها؛ «بررسی وضعیت» فقط برای تپسی فود |
| 4 | «سفارش در اسنپ فود/تپسی فود» | اپ پلتفرم یا صفحهٔ وب باز می شود (خطا را با اسکرین شات بفرستید) |
| 5 | «نزدیک من» در بسفود | پرسش مجوز موقعیت فقط پس از لمس؛ بدون مجوز هم جست وجو ادامه دارد |
| 6 | رهیاب ← مبدأ: «موقعیت من» (مجوز GPS)، مقصد: «دانشگاه فردوسی» یا «غدیر» ← مسیر را پیدا کن | حداکثر دو کارت (مثلاً خودرو و مترو) با خروج، رسیدن، پاها و برچسب «اندازه گیری/مدل/فرض»؛ «اگر قطار را از دست بدهید» |
| 7 | رهیاب بدون GPS: مبدأ را تایپ کنید | ایستگاه ها و یک نشانی تقریبی؛ توضیح «نقطهٔ تقریبی» |
| 8 | بسخرید ← «پاوربانک» ← «مقایسهٔ فروشندگان» ← «مشاهده در تکنولایف» | قیمت ها با تاریخ، «موجودی و ارسال نامعلوم»؛ لینک به تکنولایف |
| 9 | بسخرید ← «flip» ← مقایسه | هر سه فروشنده «چند قیمت متفاوت؛ تنوع نامشخص»، بدون قیمت منتخب |
| 10 | بسراه (مترو) ← تابلو، نمای خط، خط ۱ و ۲ | همان رفتار قبلی R3-C؛ دکمهٔ بازگشت تلگرام و کلید Back درست کار کند |
| 11 | کیبورد باز در جست وجوی بسفود یا رهیاب | نوار پایین نباید روی ورودی ها یا دکمه ها بیفتد (اسکرین شات بفرستید) |
| 12 | حالت تیره و روشن | همهٔ متن ها خوانا |

برای هر مشکل: اسکرین شات + آدرس/کد خطا (اگر دارید) + مدل گوشی. iOS: `NOT_TESTED`.

## جریان های بازتولیدپذیر (curl، همین سرور)

1. غذا: `GET /api/food/search?q=چلو کباب&limit=3` ← `total>0`، `snapshot.stale=true`، هر `matched[].priceState` یکی از `known|unknown`.
2. منوی فروشنده: `GET /api/food/vendor?id=<id از جواب بالا>` ← `menu[]`، `orderUrl`.
3. خرید: `GET /api/shop/search?q=پاوربانک` ← ۲ کالا، `priceState=compared`.
4. محصول: `GET /api/shop/product?id=tl:109067` ← فروشندگان با `state` و `stock:"unknown"`.
5. حل نشده: `GET /api/shop/product?id=tl:100996` ← همهٔ پیشنهادها `unresolved`، `priceToman=null`.
6. مکان: `POST /api/places` با `{"q":"شریعتی"}` ← ایستگاه + یک `address` با `precision:"geocoded"`.
7. مسیر: `POST /api/trip` با `{"from":{"lat":36.3079,"lon":59.5971},"to":{"lat":36.2569,"lon":59.6203}}` ← حداکثر ۲ گزینه.
8. بدون مسیریاب (آزمون): سرور بدون `BESRAH_NESHAN_KEY` ← `status:"partial"`، `arriveAt:null`.
9. روش ها: `GET /api/trip` ← 403؛ `POST` با `text/plain` ← 415؛ خارج از مشهد ← 422.
10. مترو: `GET /api/next?station=غدیر` و `GET /api/trains?line=2` ← بی تغییر نسبت به R3-C.

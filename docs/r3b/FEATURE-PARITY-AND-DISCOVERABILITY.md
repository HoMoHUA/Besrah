# Feature parity & discoverability — R3-B

KEEP = بدون تغییر رفتار؛ MERGE = ادغام در یک کنترل؛ UPGRADE = همان قابلیت بهتر؛ DEPRECATE = حذف با جانشین؛ UNKNOWN = نیازمند بررسی. «کشف پذیری» = راه یافتن توسط کاربر عادی، بدون باز کردن `<details>`. تست ها در `apps/miniapp/metro-r3b.test.mjs` (نام کوتاه) یا تست های قبلی.

| قابلیت | قبل (R3-A) | بعد (R3-B، حالت ON) | کشف پذیری | وضعیت | تست |
|---|---|---|---|---|---|
| Home → ایستگاه/تایل ها (`go('metro',{mode})`) | ورود به مترو، `onShow({mode})` | بدون تغییر؛ `line2`/`all` خط مشترک یا پنل «ایستگاه ها» را باز می کند | مستقیم | KEEP | `explicit route line2…` (قدیمی)، `home mode…` |
| Saved / Favorites view (`go('favourites')`) | دکمهٔ «ایستگاه های من» در ردیف میان بر | لینک «ایستگاه های من» داخل انتخابگر + چیپ های علاقه مندی؛ صفحهٔ Favorites بدون تغییر | با لمس فیلد مبدأ/مقصد؛ و از تب Saved/Home | MERGE | `picker shortcuts…` |

UNKNOWN: ندارد. DEPRECATE: فقط ردیف دکمهٔ بزرگ `metro-quick` (جانشین: چیپ های انتخابگر)، `<details>` ردیاب/فهرست (جانشین: سوئیچر زمینه)، select خط/زمان تعبیه شده (جانشین: چیپ ها). قابلیت ها حذف نشدند.

## بازبینی مرورگر مستقل (پس از پیاده سازی؛ Preview واقعی، Chromium)

شواهد: `PARITY-BROWSER-CHECK-1.json`، `PARITY-BROWSER-CHECK-2.json`.

| سناریو | نتیجه |
|---|---|
| Preview با Beta خاموش (بازدیدکنندهٔ عادی) | صفحهٔ legacy با جست وجو، ردیاب و فهرست؛ بدون کارت برنامه ریز و بدون دکمهٔ ورود؛ overflow صفر |
| Beta روشن، بازدیدکنندهٔ تازه | همان legacy؛ «ورود اختیاری به سفر آزمایشی» دیده می شود؛ فقط `besrah.beta.bucket` در storage |
| ورود، سپس «خروج از حالت آزمایشی» | بازگشت کامل به legacy؛ ردیاب، فهرست و جست وجو سالم؛ دکمهٔ ورود دوباره دیده می شود |
| تب اتوبوس | صفحهٔ اتوبوس باز می شود؛ مترو پنهان |
| ذخیرهٔ ایستگاه از پنل تابلو | تغییر دکمه به «حذف از علاقه مندی ها» |
| انتخابگر مقصد | چیپ علاقه مندی و لینک «ایستگاه های من»؛ «نزدیک ترین ایستگاه» عمداً فقط برای مبدأ است (`planner.js`: `choose(..., 'from')`)، پس برای مقصد دیده نمی شود |
| لینک «ایستگاه های من» → صفحهٔ Favorites → لمس ایستگاه | برگهٔ کامل ایستگاه با تابلو، بازخوانی، قلب و «از این ایستگاه سفر بساز» |
| «از این ایستگاه سفر بساز» | بستن برگه، بازگشت به مترو، مبدأ = ایستگاه، تابلوی همان مبدأ، پنل پیش فرض «حرکت های ایستگاه» |

نزدیک ترین ایستگاه با لمس صریح و بدون geolocation هنگام ساخت صفحه در تست واحد پوشش دارد؛ در این بازبینی مرورگر GPS درخواست نشد.

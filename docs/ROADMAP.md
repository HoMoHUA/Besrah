# Roadmap

فاز ۰ (هسته‌ی مترو، درست و قابل تست)
- ساخت `network.json` ✔ (این بسته)
- هسته‌ی `nextDepartures` + تست طلایی
- جایگزینی Time-Cal در n8n با فراخوانی HTTP
- برداشت میدانی بعدی: روز عادی و پنج‌شنبه، برگشت شریعتی→وکیل‌آباد، توسعه‌ی غدیر→فرودگاه (سواری)، خط ۲ بخش طبرسی→شریعتی

فاز ۱ پایه‌ی داده: GTFS (با frequencies.txt)، PostGIS، گراف پیاده‌روی OSM
فاز ۲ موتور مسیریابی ترکیبی (RAPTOR + پیاده)، ژئوکد آدرس‌های مشهد
فاز ۳ مقایسه با خودرو/تاکسی، تخمین کرایه، deep link اسنپ و تپسی
فاز ۴ اتوبوس تقریبی (سرفاصله‌ی حدودی، بازه‌ی انتظار)
فاز ۵ موتور زنده: گزارش کاربران، یادگیری تأخیر، رویدادها
فاز ۶ وب‌اپ PWA
فاز ۷ ارائه به پارک نوآوری و شهرداری، درخواست دسترسی به داده‌ی رسمی (جدول و GPS)
